# Outside the Box BC CanSPEP 2026 Landing Page

Static QR campaign landing page for `canspep26.outsidetheboxbc.ca`.

## Structure

- `index.html` contains the full landing page, styles, and accordion script.
- `assets/logos/` contains the Outside the Box BC logo files.
- `assets/photos/` contains web-sized campaign images.
- `assets/fonts/Corben/` contains the locally hosted Corben font files.
- `assets/references/` contains the project brief and source reference PDFs.

## Publishing

Upload the contents of this folder to the web root for `canspep26.outsidetheboxbc.ca`.

For GitHub Pages, set the repository Pages source to the branch/folder that contains this `index.html`.

## Notes

- The page uses local Corben font files, so it does not depend on Google Fonts during the conference.
- The page is currently set to `index, follow` based on project-owner preference.
- The primary CTA is consistently `Visit Outside the Box BC` and points to `https://www.outsidetheboxbc.ca/`.
